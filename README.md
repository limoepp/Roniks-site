# Сайт салона красоты «Роникс»

Сайт с прайсом, акциями месяца, записью и простой админкой для сотрудников.
Работает на любом хостинге с PHP 8.1+ — без базы данных, все данные лежат в папке `data/`.

## Что есть на сайте

- **Главная** — поиск услуги с ценами прямо в первом экране, акции месяца, направления с ценой «от», способы записи, о салоне, карта.
- **Цены** (`/ceny/`) — весь прайс на одной странице: мгновенный поиск (понимает «покраска», «шеллак», «ногти» и т. п.), фильтр по направлениям, кнопка «Записаться» у каждой услуги.
- **Услуги** (`/uslugi/…`) — отдельная страница на каждое направление с подразделами и акциями этого направления.
- **Акции** (`/akcii/`) — заголовок страницы сам меняется по месяцу («Акции ноября»), акции показываются по датам.
- **О салоне**, **Контакты**, **Политика обработки персональных данных**, sitemap.xml и robots.txt.
- **Запись**: любая кнопка «Записаться» открывает окно — WhatsApp с готовым текстом («Хочу записаться: Окрашивание Lebel»), Telegram, звонок, онлайн-запись (если указать ссылку) и форма «Перезвоните мне».
- На телефоне снизу всегда есть панель «Позвонить / WhatsApp / Записаться».

## Админка: `/admin`

| Раздел | Что можно делать |
|---|---|
| Цены и услуги | Менять цены и названия, добавлять/удалять/переставлять услуги и подразделы, варианты цен (по длине волос, по времени), «от», скрывать услуги. Поиск по всем услугам. **Массовое изменение цен на %** с округлением. Новые разделы (например, «Косметология»). |
| Акции | Новая акция с ценой «было/стало», плашкой, датами, картинкой. Акция сама появляется и исчезает по датам. Кнопка **«Повторить»** копирует акцию на следующий месяц. |
| Заявки | Заявки из формы «Перезвоните мне», отметки «Перезвонили / Записан», выгрузка в Excel. |
| Контакты и настройки | Телефоны, мессенджеры, часы работы, ссылка на онлайн-запись, адрес, тексты о салоне, реквизиты, уведомления о заявках на почту и в Telegram. |
| Мастера, Фото салона | Блоки появляются на сайте, как только что-то загружено. Фото сами уменьшаются и очищаются от метаданных. |
| Резервные копии | Перед каждым сохранением запоминается прошлая версия (последние 60) — любую правку можно откатить. |

**Первый вход после клонирования:** выполните `php -c php-local.ini scripts/setup.php`. Скрипт создаст отсутствующие локальные файлы и покажет случайный временный пароль. При первом входе задайте свой пароль.

**Забыли пароль:** через файловый менеджер хостинга положите в папку `data/` файл `reset-password.txt`, внутри — новый пароль. Откройте `/admin`: пароль заменится, файл удалится, после входа сайт попросит задать постоянный пароль.

## Запуск на своём компьютере

Нужен PHP 8.1 или новее.

- **Windows:** скачайте PHP с https://windows.php.net/download (Thread Safe, zip), распакуйте, например, в `C:\php`. Либо поставьте OSPanel/XAMPP и положите папку сайта в их каталог сайтов.
- **macOS:** `brew install php`.

Затем в папке сайта:

```
php -S localhost:8000 router.php
```

Откройте http://localhost:8000 — сайт, http://localhost:8000/admin — админка.

## Размещение на хостинге

1. Хостинг с PHP 8.1+ (подходит почти любой: Beget, Timeweb, REG.RU, Sprinthost и т. п.). Расширения: `gd` (для фото), `curl` (для Telegram-уведомлений), `mbstring` — обычно включены.
2. Загрузите содержимое папки в корень сайта (там, где `index.php`). Файл `router.php` на хостинге не нужен, но и не мешает.
3. Папки `data/` и `uploads/` должны быть доступны PHP на запись.
4. Включите HTTPS (бесплатный сертификат Let's Encrypt есть у всех хостингов).
5. Зайдите в `/admin`, смените пароль, проверьте контакты.

На Apache всё настроено через `.htaccess` (закрыты `data/` и `app/`, в `uploads/` не исполняются скрипты). Для nginx:

```
location ~ ^/(data|app)/ { deny all; }
location ~ ^/uploads/.*\.(php|phtml|phar)$ { deny all; }
location / { try_files $uri /index.php?$query_string; }
```

## Устройство

```
index.php            маршруты сайта
router.php           для локального запуска (php -S)
app/core.php         данные, форматирование цен, иконки, безопасность
app/views/           страницы сайта
app/admin/           админка
app/lead.php         приём заявок
assets/              стили, скрипты, шрифты (Literata и Golos Text, свои файлы — без Google Fonts)
data/*.json          цены, акции, настройки, мастера, фото, заявки, резервные копии
uploads/             загруженные картинки
DESIGN.md            цвета, шрифты, отступы и компоненты
```

Безопасность админки: пароль хранится в виде хеша, защита от подбора (10 попыток за 15 минут), CSRF-токены на всех действиях, сессия только для `/admin`, проверка и пересохранение загружаемых картинок. Форма заявки защищена от ботов скрытым полем, подписанной меткой времени и ограничением частоты.
