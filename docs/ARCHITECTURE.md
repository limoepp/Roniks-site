# Архитектура и эксплуатация

## Карта системы

Запрос браузера → `router.php` локально / `.htaccess` на Apache → `index.php` → `app/core.php` → шаблон страницы → общий `app/views/layout.php` → HTML + `assets/css/site.css` + `assets/js/site.js`.

| Компонент | Ответственность |
|---|---|
| `index.php` | Публичные маршруты, SEO-файлы, передача в админку и API |
| `app/core.php` | JSON, выборки услуг/акций, шаблоны, URL, форматирование, CSRF, сессии, лимиты |
| `app/views/` | Главная, цены, направления, акции, о салоне, контакты, политика |
| `app/views/partials/` | Прайс, акция, мастера, окно записи, контакты/карта |
| `app/admin/admin.php` | Авторизация, маршруты редактирования и сохранение |
| `app/admin/views/` | Интерфейс администрирования |
| `app/lead.php` | Проверка заявки, сохранение и уведомления |
| `data/services.json`, `data/promos.json` | Версионируемое публичное содержимое |
| Остальные `data/`, `uploads/` | Локальные данные, учётные данные, заявки, изображения; вне Git |
| `scripts/setup.php` | Инициализация отсутствующих локальных файлов после клонирования |
| `assets/css/keri.css` (ветка B) | Изолированные переопределения оформления через `.keri-theme` |
| `scripts/export-demo.py` (ветка B) | Отрендеренные публичные страницы без админки и приёма заявок |

## Данные и границы

Цены описаны категориями → группами → услугами → вариантами цен. Одна услуга может иметь цены по длине волос или длительности. Акции показываются по признаку активности и диапазону дат. JavaScript фильтрует уже отрендеренный прайс; отдельного серверного поискового API нет.

Настройки включают контакты и ключи уведомлений, поэтому рабочий settings.json исключён из Git. settings.example.json содержит образец без ключей. Заявки и учётные данные не должны попадать в статический экспорт, GitHub или видеозапись.

## Запуск

1. PHP 8.1+, расширения mbstring, gd, curl, fileinfo, openssl.
2. После клонирования: `C:\php\php.exe -c php-local.ini scripts/setup.php`.
3. Запуск: `C:\php\php.exe -c php-local.ini -S 127.0.0.1:8000 router.php`.
4. Админка: `/admin`. Временный пароль выводит setup; хранить локально, при первом входе сменить.

В одной папке при переключении ветки игнорируемые данные остаются общими. Для параллельных локальных серверов использовать разные рабочие каталоги и порты.

## Демонстрационные публикации

Sites размещает статический HTML, но не исполняет PHP. Поэтому демоверсия — экспорт отрендеренных публичных страниц с локальными ресурсами. Полный PHP-сайт остаётся в GitHub. Экспорт не синхронизируется с админкой автоматически.

В B `layout.php` подключает `keri.css` после базового `site.css`; `prices.php` задаёт сетку боковой навигации и прайса. Селекторы поведения `data-filter`, `data-price-search`, `data-book` сохранены: используется прежний `site.js`, отдельной реализации поиска или записи нет. Админка не использует `.keri-theme`. Базовый `site.css` и публичные данные не изменены. Воспроизведение экспорта и видео описано в DEMO-WORKFLOW.md.

В редакции B2 `home.php` строит баннер, направления и блоки фотографий. `assets/js/keri.js` отвечает только за ручное переключение баннеров; автопрокрутки нет. `partials/salon-photo.php` читает существующую gallery() и показывает фото либо подписанную заглушку. Страница about.php всегда содержит `#gallery`, в том числе до загрузки фото. Шрифт Montserrat и лицензия находятся в assets/fonts, внешней загрузки шрифтов нет. Параметры референса и правила заполнения — DESIGN-REFERENCE.md.

У A и B разные Sites project_id и URL; никогда не подставлять идентификатор A для публикации B. Идентификаторы и ссылки фиксируются в STATUS после успешного размещения. В демо обязательны: заметная маркировка, запрет приёма заявок, отключённые переходы к звонкам/мессенджерам, noindex и отсутствие служебных данных.

## Известные ограничения

- JSON-блокировка охватывает запись, но не весь цикл чтения/изменения: возможна потеря параллельных правок. Перед рабочим приёмом заявок исправить или перейти на транзакционное хранилище.
- Проверить маршрут `/admin/prices/order`: общий `/prices/{id}` может перехватывать слово order.
- Конфигурацию Apache/nginx проверять отдельно. В текущем дереве существуют защитные `app/.htaccess`, `data/.htaccess`, `uploads/.htaccess`; прежнее замечание об отсутствии uploads/.htaccess устарело.
- Успешная заявка, уведомления, загрузка изображений и операции авторизованной админки ещё не проходили полную проверку.
- Фото, команда, реквизиты, прайс и контакты требуют подтверждения салоном.
