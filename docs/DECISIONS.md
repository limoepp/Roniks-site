# Решения

## 2026-11-13 — Сохранить PHP и JSON на этапе согласования
Изменение дизайна не требует смены стека. Отдельно вести технические ограничения JSON и задачи перед рабочим запуском.

## 2026-11-13 — Два оформления в двух ветках
`main` — вариант A (тёмно-зелёный, ягодный, заголовки Literata). `design/keri-style` — вариант B (светлый, мягкие зелёные/розовые акценты, компактная типографика, боковая навигация по прайсу на компьютере). До выбора заказчика не заменять A.

## 2026-11-13 — Сравнивать по двум ссылкам
Ветки нужны разработчику, демоссылки — заказчику. Содержимое должно совпадать, чтобы сравнивалось оформление. Статистический A/B-тест до рабочего запуска не нужен.

## 2026-11-13 — Демонстрация не принимает реальные заявки
В опубликованных копиях нет рабочей админки, личных данных и ключей. Заявки и переходы к звонкам/мессенджерам отключены. Ссылка общедоступна по прямому запросу пользователя; noindex не является защитой доступа.

## 2026-11-13 — Постоянный контекст в репозитории
AGENTS.md задаёт правила, PROJECT.md — навигацию, STATUS — проверенные факты, PLAN — будущие задачи, ARCHITECTURE — карту системы, DECISIONS — причины решений. Записи о публикациях и видео обновляются только после проверки результата.

## 2026-11-13 — Ролики без звука и посторонних окон
Использовать браузерный источник OBS с URL публикации и отдельную сцену. Микрофон и системный звук заглушены; итоговую копию отдавать без аудиодорожек. Первый ролик записан в 1920×1080, 60 fps, 156,87 секунды.

## 2026-11-13 — Переработать B по измеренному референсу
Пользователь отклонил B1 как недостаточно похожую на «Кэри». В B2 использовать Montserrat, реальные мятные/розовые заливки и лиловый баннер референса, двухрядную шапку и крупные карточки направлений. На главной и странице «О салоне» явно показать места для фотографий; использовать существующую галерею вместо новой системы данных. Yclients подключать позднее. Видео B1 сохранить как историю, не предлагать как актуальный обзор B2. Работа разрешена в design/keri-style; main и демо A сохранены.
