# Редакция B2: ориентир — сайт «Кэри»

## Запрос и границы
13.11.2026 пользователь отклонил B1 как недостаточно похожую на «Кэри» и разрешил переработку design/keri-style. Нужно воспроизвести узнаваемую визуальную систему главной и внутренних страниц, адаптировав её под салон «Роникс». MVP остаётся демонстрацией; подключение Yclients — следующий этап. main и демо A не изменять.

## Измеренный референс
Источник — https://keri.ru/ и https://keri.ru/ceny/, просмотренные в реальном браузере. В отличие от предположений B1 параметры взяты из вычисленных стилей:

| Элемент | Значение |
|---|---|
| Шрифт основного интерфейса | Montserrat, веса 400–700 |
| Мятная кнопка шапки | #7DB6AA |
| Розовая кнопка баннера | #ED87AF |
| Фон баннера | linear-gradient(95.32deg, #F0EFF5 19.35%, #FBF8FF 89.65%) |
| Основной тёмный текст | #0C1C2B |
| Скругление баннера | 24px |
| Скругление основных кнопок | 30px |
| Шапка | Логотип, адрес, часы, телефон, мессенджеры, запись; отдельная строка навигации |
| Главная | Крупный баннер, карточки направлений, знакомство с организацией |
| Прайс | Направления слева, округлый поиск, светлые таблицы/группы справа |

Цвета заливок сохранены. Для небольшого текста и надписей на пастельных кнопках у «Роникса» используются более тёмные оттенки, чтобы сохранить читаемость. Логотип и содержание адаптированы под салон; медицинские реквизиты, фотографии клиники и услуги «Кэри» не переносились. Montserrat хранится локально, источник — Google Fonts, лицензия OFL рядом со шрифтом.

## Где размещаются фотографии
1. Главная: справа от текста первого баннера — первое фото из раздела «Фото салона».
2. Главная: рядом с текстом знакомства — второе фото галереи (при отсутствии остаётся заглушка).
3. Главная: «Пространство салона» — первые три фото галереи.
4. «О салоне» → `#gallery`: все загруженные фотографии. В меню и подвале есть ссылка «Фото салона».
5. Карточки направлений используют изображения категорий из «Цены и услуги»; у акций есть собственное изображение. Пока изображений нет, показаны явно подписанные места под них.

Общий partial `app/views/partials/salon-photo.php` показывает имеющееся изображение или графическую заглушку. Заглушка — схема, а не фотография реального интерьера. Не выдавать её за снимок салона. После загрузки фотографий повторно экспортировать демо; статический сайт не читает админку автоматически.

## Будущая запись через Yclients
Все кнопки используют существующий `data-book` и общий диалог. В настройках PHP-проекта уже предусмотрено `booking_url`; на следующем этапе согласовать ссылку/сценарий Yclients и проверить переходы, работу на телефоне и контекст выбранной услуги. Сейчас реальный виджет и интеграция не подключены, заявки в демо отключены. Не указывать на сайте, что Yclients уже работает.

## Проверка результата
Оценивать рядом с референсом шапку, шрифт, цвета, крупный баннер, направления и прайс. Проверять главную и цены на 320/768/1024/1440, баннер кнопками и клавиатурой, мобильное меню, поиск, возврат фокуса после закрытия записи и отсутствие живой формы в статическом экспорте. Старое видео B1 больше не демонстрирует текущий B2.
