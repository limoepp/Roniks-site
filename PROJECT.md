# Роникс — точка входа в проект

Сайт салона красоты для просмотра услуг, цен, акций и записи через администратора. Заказчик также владеет клиникой «Кэри». Сейчас задача — сравнить два оформления и получить обратную связь.

## Где искать информацию
| Документ | Назначение |
|---|---|
| `AGENTS.md` | Правила продолжения работы для ассистентов |
| `docs/STATUS.md` | Актуальное состояние, публикации, проверки и следующий шаг |
| `docs/PLAN.md` | План текущего этапа и очередь дальнейших работ |
| `docs/ARCHITECTURE.md` | Устройство, данные, запуск и публикация |
| `docs/DECISIONS.md` | Принятые решения и основания |
| `docs/DEMO-WORKFLOW.md` | Повторение экспорта, публикации и записи видео |
| `docs/CLIENT-REVIEW.md` | Памятка заказчику, предварительные материалы и админка |
| `README.md` | Возможности и инструкции работы с PHP-сайтом |
| `DESIGN.md` | Базовое оформление варианта A |
| `DESIGN-COMPARISON.md` | Правила сравнения вариантов |

Репозиторий: https://github.com/limoepp/Roniks-site (публичный).

Не путать три результата: ветка содержит исходники; демоссылка показывает опубликованный снимок; видео показывает взаимодействие с конкретной публикацией. Готовность каждого отмечается отдельно в STATUS.
